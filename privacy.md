# Privacy policy

Last updated: 25 November 2026

This privacy policy covers a personal OAuth client for rclone. The only person who uses it is the owner of this GitHub account.

Data accessed: only the files and folders that rclone itself creates in the owner's own Google Drive (Google scope drive.file). The client cannot see any other files.

Data use: files are copied only between the owner's own computers and the owner's own Google Drive. No data is collected or stored on any server run by this app. Nothing is sold, shared with third parties, or used for advertising.

Revoking access: the owner can remove access at any time at https://myaccount.google.com/permissions.

Contact: through the GitHub account that publishes this page.
