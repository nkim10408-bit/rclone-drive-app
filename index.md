# rclone Drive backup (personal)

This page belongs to a personal, single-user OAuth client. Its only user is the owner of this GitHub account.

The client is used with rclone, an open-source file sync tool (https://rclone.org), to copy files that rclone itself creates into the owner's own Google Drive.

It is not a public service and has no other users.
